# Черновик документации
## Философия проекта
Данный набор скриптов расчитан на продвинутых пользователей, которые хотят получить очень гибкую настройку установки Arch Linux но с минумумов излишних телодвижений: просто задай желаемые настройки в XML-файле, а все остальное сделает скрипт!


Во время установки системы взаимодействие с пользователем сведено к минимуму, максим информации скрипт берёт из предварительно настроенного конфигурационно файл, а именно по сути всё за исключением пароля нового пользователя и новых ключей шифрования, если его использование задано в настройках.
Навания вариатов прописанных настроек либо как исключение так же запрашиваются у пользователя скриптом либо их можно будет сразу указать через ключи во время запуска скрипта.

## Формат настроек в  XML-файле
XML-файл имя которого по умолчанию [components.xml](components.xml) в своей структре разбит на 4 секции:
* **Пакеты драйверов** -- тег driverpacks
* **Набор софта** -- тег softpacks
* **Установочные локейшны** -- тег install_locations
* **Прочие различные параметры** -- тег settings_variants
Позже описание структуры данного файла будет подробно задокументирована.

## Треборания перед установкой
Помимо предварительного внесения желаемых настроек в xml-файл, требуется так же:
* **Настроить работу интренета**, который необходим для скачивания пакетов через pacman.
При проводном подключении через Ethernet интернет в подавляющем большинстве случаев подключиться автоматически. Если же для подключения доступен только Wi-Fi, то в каталоге со скриптом присутствую также дополнительные Readme-файлы, два из которых подключенные подключению Wi-Fi прямо из из TTY:
  * [README-wifi-iwctl(iwd).md](README-wifi-iwctl(iwd).md) -- подробная инструкция по испольнию утилиты, которая предустановленая на установочный iso-образ Arch Linux'а. 
  * [README-wifi.md](README-wifi.md) -- инструкция по подключению в Wi-FI из TTY используя NetworkManager. Это требует чуть меньше телодвижений, но официальном установочном iso-шнике NetworkManager'а нет и там нужно будет использовать предыдуший вариант. Тем не менее данная инструксия может быть полезна при работе на уже истановленной системе, не которой графическая среда не установлена или не запущена.
* **Выполнить правильную разметку диска** в соответствии с заданными настройками
  * Нужно предварительно созадать если уже не создано:
    * группы томом LVM (если используются)
    * разделы отформатированные в Btrfs (вне зависимоти логические ли это тома LVM или разделы в основной разметке диска)
  * Не нужно предворительно создавать (или будет ошибка):
    * сабволюмы (подтома) на файловых системах btrfs
    * логические LVM-тома, если на них будет использоваться ext4, а не btrfs
  * Разделы в основной разметки для форматирования в ext4 нужно также обязательно создать, хоть заранее форматировать их в ext4 их не обязательно (хотя и не запрещено)
