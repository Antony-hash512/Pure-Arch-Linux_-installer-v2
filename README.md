# Черновик документации
## Философия проекта
Данный набор скриптов рассчитан на продвинутых пользователей, которые хотят получить очень гибкую настройку установки Arch Linux, но с минимум излишних телодвижений: просто задай желаемые настройки в XML-файле, а все остальное сделает скрипт! Единственное что нельзя задать в конфигурационном файле это разве что пароль пользователя или пароль для шифрования диска (если оно используется)

## Формат настроек в XML-файле
XML-файл имя которого по умолчанию [components.xml](components.xml) в своей структуре разбит на 4 секции:
* **Пакеты драйверов** -- тег driverpacks
* **Набор всего остального софта** -- тег softpacks
* **Установочные локейшны** -- тег install_locations
* **Прочие различные параметры** -- тег settings_variants

Позже описание структуры данного файла будет подробно задокументирована.

## Требования перед установкой
Помимо предварительного внесения желаемых настроек в xml-файл, требуется так же:
* **Настроить работу интеренета**, который необходим для скачивания пакетов через pacman.
При проводном подключении через Ethernet интернет в подавляющем большинстве случаев подключиться автоматически. Если же для подключения доступен только Wi-Fi, то в каталоге со скриптом присутствуют также дополнительные Readme-файлы, два из которых посвящены подключению Wi-Fi прямо из TTY:
  * [README-wifi-iwctl(iwd).md](README-wifi-iwctl(iwd).md) -- подробная инструкция по использованию утилиты, которая предустановленная на установочный iso-образ Arch Linux'а. 
  * [README-wifi.md](README-wifi.md) -- инструкция по подключению в Wi-FI из TTY используя NetworkManager. Это требует чуть меньше телодвижений, но официальном установочном iso-шнике NetworkManager'а нет и там нужно будет использовать предыдущий вариант. Тем не менее, данная инструкция может быть полезна при работе на уже установленной системе, на которой графическая среда не установлена или не запущена.
* **Выполнить правильную разметку диска** в соответствии с заданными настройками
  * Нужно предварительно создать если уже не создано:
    * группы томов LVM (если используются)
    * разделы отформатированные в Btrfs (вне зависимости логические ли это тома LVM или разделы в основной разметке диска) если планируется использовать данную файловую систему
  * Не нужно предварительно создавать (или будет ошибка):
    * прописанные в конфиге сабволюмы (подтома) на файловых системах btrfs
    * прописанные в конфиге логические LVM-тома, если на них будет использоваться ext4, а не btrfs
  * Разделы в основной разметке для форматирования в ext4 нужно также обязательно создать, хотя заранее форматировать в ext4 их не обязательно (хотя и не запрещено)
  * Криптоконтейнеры для для физических томов lvm или партишнов/томов с btrfs нужно также создать вручную перед установкой. Шифрование же партишнов или логических томов lvm с ext4 скрипт наоборот создаёт автоматически.
  Список комманд, которые могут пригодиться во время предустановочной разметки диска находится в [README.preinstall.md](README.preinstall.md)
